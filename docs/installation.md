# Installation

## Stable release

To install rw5lib, run this command in your terminal:

```sh
uv add rw5lib
```

Or if you prefer to use `pip`:

```sh
pip install rw5lib
```

## From source

The source files for rw5lib can be downloaded from the [Github repo](https://github.com/j-osephlong/rw5lib).

You can either clone the public repository:

```sh
git clone git://github.com/j-osephlong/rw5lib
```

Or download the [tarball](https://github.com/j-osephlong/rw5lib/tarball/main):

```sh
curl -OJL https://github.com/j-osephlong/rw5lib/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd rw5lib
uv pip install .
```
